# 이미지 교체 안내

채팅에 첨부해주신 5장의 사진은 대화 안에서 시각적으로만 확인 가능하고,
이 세션의 파일시스템으로 직접 저장할 수 있는 방법이 없어 실제 파일로
내려받지 못했습니다. 대신 아래 파일명 그대로 이 `images/` 폴더에
넣어주시면 사이트에 자동으로 반영됩니다 (별도 코드 수정 불필요).

| 파일명 | 들어갈 사진 | 권장 비율 |
|---|---|---|
| `hero-front.jpg` | 정면, 시선 아래로 향한 스튜디오 컷 (1번 사진) | 세로형 (예: 4:5 이상) |
| `hero-back.jpg` | 뒷모습, 벽 앞에 선 컷 (2번 사진) | 세로형 4:5~4:6 |
| `fabric-detail.jpg` | 원단 클로즈업 매크로 컷 (3번 사진) | 세로형, 정사각에 가까워도 무방 |
| `lifestyle-full.jpg` | 정면 전신, 카메라 응시 컷 (4번 사진) | 세로형 4:6 |
| `packaging-flatlay.jpg` | 티셔츠·파우치·박스 플랫레이 (5번 사진) | 세로형 4:5 |

파일을 넣기 전까지는 브랜드 톤(크림/베이지)에 맞춘 그라데이션
플레이스홀더가 대신 표시되도록 `onerror` 처리를 해두었습니다.
`.jpg` 대신 `.png`나 `.webp`를 쓰실 경우, `index.html`에서 해당
`src` 확장자만 맞춰 바꿔주세요.
